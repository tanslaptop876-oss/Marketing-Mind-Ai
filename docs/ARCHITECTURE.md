# Marketing Mind AI Architecture

## Core modules

1. **Brand Intelligence** — brand voice, offers, audience personas, goals and constraints.
2. **Strategy Engine** — campaign objectives, funnel stages, channel strategy and content pillars.
3. **Content Engine** — briefs, drafts, variants, CTAs and reusable content assets.
4. **SEO Engine** — keywords, search intent, topic clusters, on-page recommendations and content scoring.
5. **Social Engine** — channel-specific adaptation, scheduling metadata and publishing adapters.
6. **Campaign Engine** — campaign plans, assets, budgets/targets metadata and experiment tracking.
7. **Analytics Engine** — normalized performance metrics, attribution inputs and recommendation scoring.
8. **Dashboard/API** — user-facing workflow and integrations.

## MVP flow

Brand profile -> Audience -> Campaign goal -> Strategy -> Content plan -> Draft assets -> Review -> Publish/export -> Metrics -> Recommendations

## Safety and product principle

AI output is decision support. Publishing and paid-campaign actions should require explicit user approval before external execution.
